=====================================
Anglo-Saxon ITR consolidation Booking
=====================================

|

This module adds a wizard that generates an accounting entry
to reclassify the Debit ITR (Invoice To Receive GL account) entries to two specific accounts.

|

Configuration
=============

Go to **Accounting > Configuration > Settings > Anglo-Saxon ITR consolidation Booking**

Configure the GL accounts.

|

Usage
=====

Generate accounting entry
-------------------------

Go to **Accounting > Actions > Generate Anglo-Saxon ITR consolidation entry**

A wizard allows to select the accounting period for which such an accounting entry
will be created.

A warning will be given when unreconciled ITR Debit entries are found.
