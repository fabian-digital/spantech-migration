====================================
Account Analytic Default on Invoices
====================================

This module allows to set an Analytic Distribution on an invoice which serves as default for the invoice lines.

Via a config setting you can also enforce that the analytic distribution becomes mandatory on invoice lines.


Configuration
=============

Configuration available in Accounting Settings (Settings > Accounting > Analytic Mandatory)
