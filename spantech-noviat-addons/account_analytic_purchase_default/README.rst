=====================================
Account Analytic Default on Purchases
=====================================

This module allows to set an Analytic Account on a Purchase Order which serves as default for the purchase order lines.

Via a config setting you can also enforce that this field becomes mandatory.


Configuration
=============

Configuration available in Accounting Settings (Settings > Accounting > Analytic Mandatory)
