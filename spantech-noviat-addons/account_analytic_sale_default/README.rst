=================================
Account Analytic Default on Sales
=================================

This module allows to set an Analytic Account on a Sale Order which serves as default for the sale order lines.

Via a config setting you can also enforce that this field becomes mandatory.


Configuration
=============

Configuration available in Accounting Settings (Settings > Accounting > Analytic Mandatory)
