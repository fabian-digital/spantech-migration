=========================================
Account Consolidation Mapping base module
=========================================

Base module to enable the use of the Consolidation Account in the operational Accounting views of the underlying companies. 

|

This module adds the following features:

* A security group to limit the visibility of the Consolidation Accounts in the Accounting views.
* A config parameter to select the Consolidation Chart to use for the General Account mapping.
