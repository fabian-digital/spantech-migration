==================================
Account Consolidation encoding aid
==================================

This module adds the following feature:

|

The Consolidation Account can be used as filter for the encoding of Journal Items in the companies.
As a consequence an accountant who knows the Consolidation Chart of Account will be able to encode transactions
in any of the group companies without understanding the local Chart of Accounts.
