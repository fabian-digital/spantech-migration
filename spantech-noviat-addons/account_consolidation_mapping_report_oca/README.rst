===============================================
OCA Financial Reports on Consolidation Accounts
===============================================

This module adds support for Consolidation Accounts to the following OCA financial reports:

- Trial Balance
- General Ledger

Known Issues / Roadmap
======================

The addition of the Consolidation Account is only effective when using the Excel Export.
