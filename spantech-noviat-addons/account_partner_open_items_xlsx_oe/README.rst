================================================================
Deploy account_partner_open_items_xlsx module on Odoo Enterprise
================================================================

This module places the 'Open Items per Partner' menu entry in the 'Accounting/Reporting/Partner Reports' menu
(in stead of 'Accounting/Reporting/Management').

This module will be installed automatically when following modules are activated
on your odoo database :

- account_partner_open_items_xlsx
- account_reports
