======================================
Allow payments from non AR/AP accounts
======================================

Odoo limits payment to AR/AP and bank transfer accounts.
This module allows also payments from accounts which meet following criteria:
- Type "Current Liabilities" or "Current Assets"
- Allow Reconciliation : True
