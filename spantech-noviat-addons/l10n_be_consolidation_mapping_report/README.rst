===================================================
NBB/BNB Financial Reports on Consolidation Accounts
===================================================

This module adds support for Consolidation Accounts to the Belgian Balance Sheet and P&L reports,
cf. Belgian Statements and Reports menu added by 'l10n_be_coa_multilang'.

|

As a consequence Financial Reports structured according to the Belgian Legal Scheme can
be made for legal entities using a local (non-Belgian) Chart of Account.

|

In order to run this report all accounts used in the selected legal entity must have a
Consolidation Account defined that follows the Belgian NBB/BNB reporting scheme.

|

A 'Sanity Check' button has been added to the reporting wizard.
This button check ifs all GL accounts with accounting entries in the selected report have a valid Consolidation Account.
