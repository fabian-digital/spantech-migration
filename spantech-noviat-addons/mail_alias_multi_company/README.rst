========================
Multi-company mail alias
========================

This module allows to set a different email domain per company.

This module is a base module to enable multi-company mail domains
and should be used in combination with application specific modules.

E.g. 'account_journal_multi_company_mail_alias' allows to set a different mail domain per company on financial journals.


Configuration
=============

* Go to 'Settings / Technical / External Email Servers' and configure the alias domain.
